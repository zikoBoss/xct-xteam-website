# XCT — Team Website

الموقع الرسمي لفريق **XCT** (فريق Free Fire) — بالعربية، بدرجات الأحمر والأسود، وبطاقات على شكل نوافذ تطبيقات Mac OS.

## المحتوى

- **الأدوات الحيّة للفريق** (7 أدوات): مولّد الأوتفيت، مولّد البانر، فحص الحظر، بيانات الفريق، الإيموتات، API إرسال الإيموتات، API الأيقونات.
- **عن الفريق** + **تيليغرام** (المطوّر zikoboss).

## التقنية

موقع ثابت (HTML + CSS فقط)، بلا أي بناء أو خادم — منشور على **GitHub Pages** (مجاني).

## التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر

- المستودع: `zikoBoss/xct-xteam-website`
- النشر: GitHub Pages — من الفرع `main`، المجلد `/` (root)
- الرابط: `https://zikoboss.github.io/xct-xteam-website/`
- النطاق المخصص: `zikoboss.me` (يُربط لاحقاً — يُضاف ملف `CNAME` بمحتوى `zikoboss.me` بعد ضبط DNS في Namecheap)

## التعديل

- لإضافة قناة تيليغرام أو أداة جديدة: عدّل `index.html` (بطاقة Mac جديدة) وادفع — النشر تلقائي.
